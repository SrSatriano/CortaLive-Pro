# CortaLive Pro — downloads

Este repositório guarda só os **instaladores** do CortaLive Pro (o código-fonte é fechado).

- **Baixar:** veja a [última versão](https://github.com/SrSatriano/CortaLive-Pro/releases/latest) → `CortaLive-Pro-Setup.exe`
- **Comprar uma licença:** https://srsatriano.github.io/CortaLive-Basico/
- **Como instalar e ativar:** https://srsatriano.github.io/CortaLive-Basico/instalar-pro.html

O programa só funciona depois da ativação com o e-mail e o código da compra.
A versão grátis e de código aberto (só corta vídeos) é o [CortaLive Básico](https://github.com/SrSatriano/CortaLive-Basico).
